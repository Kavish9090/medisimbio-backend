## 1. Architectural Protocols & Conventions

### 1.1 Base URL & Pathing
- All REST endpoints are versioned under `/api/v1`.
- Trailing slashes are prohibited.

### 1.2 Serialization & Timezone Standards
- **Timestamps**: Serialized in **ISO-8601 UTC** format (`YYYY-MM-DDTHH:mm:ssZ`) using Jackson's `write-dates-as-timestamps: false`.
- **Calendar Dates**: Serialized as `YYYY-MM-DD` (`LocalDate`).
- **Times of Day**: Serialized as `HH:mm:ss` (`LocalTime`).
- **Null Values**: Suppressed from output payloads using `default-property-inclusion: non_null`.

## 2. Standard Envelope Formats

### 2.1 Success Envelope: `ApiResponse<T>`
All standard non-error responses are wrapped in `ApiResponse<T>`:
```json
{
  "success": true,
  "message": "Operation completed successfully",
  "data": { ... }
}
```

### 2.2 Paginated Envelope: `PageResponse<T>`
Paginated list endpoints return data nested inside a `PageResponse<T>` structure:
```json
{
  "success": true,
  "message": "Data retrieved successfully",
  "data": {
    "content": [ ... ],
    "pageNumber": 0,
    "pageSize": 20,
    "totalElements": 48,
    "totalPages": 3,
    "first": true,
    "last": false,
    "empty": false
  }
}
```

### 2.3 Standard Error Envelope: `ErrorResponse`
Errors generated by `GlobalExceptionHandler` conform to the uniform `ErrorResponse` contract:
```json
{
  "timestamp": "2026-10-22T03:45:10.123Z",
  "status": 400,
  "error": "VALIDATION_ERROR",
  "message": "Request validation failed",
  "path": "/api/v1/appointments",
  "details": [
    {
      "field": "appointmentDate",
      "message": "Appointment date must be today or in the future",
      "rejectedValue": "2020-01-01"
    }
  ]
}
```
